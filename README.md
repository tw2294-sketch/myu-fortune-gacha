# ミューの今日の運勢ガチャ

1日1回、パーソナルAI秘書「ミュー」が今日の運勢をお届けする、小さな静的Webアプリです。
ビルド不要、サーバー不要、秘密情報なし。`index.html` を開くだけで動きます。

公開先: GitHub Pages（リポジトリ設定で `main` ブランチを公開元に指定）

## 仕様

- 運勢は日本時間（Asia/Tokyo）の日付をシードに決まるため、同じ日は誰が開いても同じ結果です。
- 1日1回は端末の localStorage でも担保します。日付が変わると再び引けます。
- 結果カードには、運勢、ひとこと、ラッキーアイテム、ラッキーカラー、ミューからのアドバイス、イラストが表示されます。
- 「結果をコピーしてシェア」で結果テキストをクリップボードにコピーできます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ本体 |
| `style.css` | デザイン（配色はネイビー／クリーム／ゴールド） |
| `app.js` | ガチャのロジック（日付シード、1日1回、シェア） |
| `fortunes.js` | 運勢データ。運用で文面を増やすのはこのファイル |
| `assets-wave.js` / `assets-desk.js` / `assets-full.js` | ミューのイラストを1点ずつ base64 data URI で保持（バイナリを置かないための方式） |

## 運用の引き継ぎメモ（他のAIエージェント向け）

- **文面を増やす**: `fortunes.js` の `window.FORTUNES` に1件追加してPRを出すだけです。形式は既存の項目に合わせ、`image` は `wave` / `desk` / `full` のいずれかを指定してください。文面は短く自然な日本語で、単語の途中で切れる表現は避けてください。
- **イラストを差し替える**: 画像は `assets-wave.js` などに1点ずつ、Web表示用に圧縮したWebPを base64 化して埋め込まれています。新画像も1ファイルあたり概ね100KB以下に圧縮してから base64 化し、該当ファイルの data URI を差し替えてください。キャラクターは全スライド、全画面で同一人物に見えることが重要です。新規に生成する場合は、既存イラストと同じ生成元から派生させ、顔立ちを並べて確認してから差し替えてください（別人化が起きやすい箇所です）。
- **公開**: GitHub Pages は `main` ブランチのルートを公開する設定です（Settings → Pages → Deploy from a branch → `main` / `/ (root)`）。`main` にマージすれば、その内容がそのまま公開側に反映されます。
- **やらないこと**: 外部APIキーや個人情報をこのリポジトリに入れないこと。集計やログイン機能を足す場合は、静的サイトの範囲を超えるので、別途設計を相談してください。

